# KAVIRAN MINING | وب‌سایت شرکتی صنایع معدنی

**KAVIRAN MINING** یک وب‌سایت شرکتی مدرن و لوکس با محوریت صنعت معدن و صنایع معدنی است که با هدف معرفی فعالیت‌ها، پروژه‌ها، تجهیزات و دستاوردهای یک مجموعه معدنی طراحی و توسعه داده شده است.

این پروژه با الهام از هویت بصری برندهای بین‌المللی صنعتی، از طراحی مینیمال، تصاویر باکیفیت، ترکیب رنگ‌های صنعتی و تایپوگرافی حرفه‌ای استفاده می‌کند تا تصویری قدرتمند و قابل اعتماد از یک شرکت معدنی ارائه دهد.

## ✨ امکانات و قابلیت‌ها

- طراحی مدرن، مینیمال و لوکس با رویکرد صنعتی
- رابط کاربری کاملاً فارسی و راست‌چین (RTL)
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- صفحه اصلی با بخش معرفی و تصویر شاخص
- معرفی شرکت و حوزه فعالیت‌های آن
- نمایش تخصص‌ها و خدمات معدنی
- معرفی پروژه‌های معدنی
- صفحه اختصاصی برای جزئیات هر پروژه
- معرفی ماشین‌آلات و تجهیزات صنعتی
- بخش مسئولیت اجتماعی، محیط زیست و HSE
- بخش اخبار و مقالات
- صفحه اختصاصی برای مطالعه جزئیات اخبار
- سیستم مسیریابی داخلی بین صفحات
- امکان بازگشت به صفحه اصلی از صفحات جزئیات
- پیمایش نرم بین بخش‌های مختلف صفحه اصلی
- تصاویر صنعتی و معدنی برای ایجاد تجربه بصری حرفه‌ای
- طراحی ساختارمند و استفاده از کامپوننت‌های مجزا

## 🛠️ تکنولوژی‌های استفاده‌شده

- **React** برای توسعه رابط کاربری
- **TypeScript** برای مدیریت نوع داده‌ها و توسعه ساختاریافته
- **Tailwind CSS** برای طراحی و استایل‌دهی
- **Lucide React** برای استفاده از آیکون‌ها
- **React Hooks** شامل `useState` و `useEffect` برای مدیریت وضعیت و رفتارهای رابط کاربری

## 🚀 نصب و راه‌اندازی

ابتدا مخزن پروژه را کلون کنید:

```bash
git clone YOUR_REPOSITORY_URL
```

وارد پوشه پروژه شوید:

```bash
cd kaviran-mining
```

سپس وابستگی‌های موردنیاز را نصب کنید:

```bash
npm install
```

در نهایت، پروژه را در حالت توسعه اجرا کنید:

```bash
npm run dev
```

پس از اجرا، آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## 📁 ساختار پروژه

ساختار اصلی پروژه بر اساس کامپوننت‌های مستقل و قابل استفاده مجدد طراحی شده است.

```text
src/
├── components/
│   ├── Navbar.tsx
│   ├── Hero.tsx
│   ├── About.tsx
│   ├── Expertise.tsx
│   ├── Projects.tsx
│   ├── ProjectDetail.tsx
│   ├── Machinery.tsx
│   ├── Sustainability.tsx
│   ├── News.tsx
│   ├── NewsDetail.tsx
│   ├── Contact.tsx
│   └── Footer.tsx
│
├── data/
│   └── index.ts
│
└── App.tsx
```

**توضیح بخش‌های اصلی:**

- `Navbar`: نوار ناوبری و مدیریت دسترسی به بخش‌های سایت
- `Hero`: بخش ابتدایی و معرفی اصلی شرکت
- `About`: معرفی مجموعه و اهداف آن
- `Expertise`: نمایش حوزه‌های تخصصی فعالیت
- `Projects`: نمایش پروژه‌های معدنی
- `ProjectDetail`: صفحه جزئیات هر پروژه
- `Machinery`: معرفی تجهیزات و ماشین‌آلات
- `Sustainability`: مسئولیت اجتماعی، محیط زیست و HSE
- `News`: نمایش اخبار و مقالات
- `NewsDetail`: صفحه مطالعه جزئیات اخبار
- `Contact`: اطلاعات و فرم ارتباط با شرکت
- `Footer`: بخش پایانی وب‌سایت
- `data`: اطلاعات پروژه‌ها و اخبار
- `App`: مدیریت ساختار اصلی برنامه، مسیریابی و وضعیت صفحات

## 🎨 هویت بصری و طراحی

در طراحی این پروژه از یک پالت رنگی صنعتی و لوکس استفاده شده است:

- ذغالی تیره
- گرافیتی
- کرم گرم
- مسی
- خاکستری متالیک

تمرکز اصلی طراحی بر ایجاد تعادل میان فضای خالی، تصاویر صنعتی، تایپوگرافی قدرتمند و جزئیات ظریف بصری بوده است.

## ⚙️ نحوه عملکرد مسیریابی

در نسخه فعلی، مسیریابی داخلی با استفاده از React Hooks و مدیریت وضعیت انجام می‌شود.

صفحات جزئیات پروژه‌ها و اخبار بر اساس `slug` مربوط به هر مورد نمایش داده می‌شوند.

همچنین در صورت انتخاب بخش‌های منوی اصلی از صفحات جزئیات، کاربر ابتدا به صفحه اصلی بازگردانده شده و سپس به بخش موردنظر هدایت می‌شود.

## ⚠️ نکات مهم

- اطلاعات پروژه‌ها و اخبار از داده‌های تعریف‌شده در بخش `data` دریافت می‌شوند.
- این پروژه در نسخه فعلی دارای ساختار فرانت‌اند است.
- اتصال به بک‌اند و پایگاه داده در ساختار ارائه‌شده پیاده‌سازی نشده است.

- آمار، پروژه‌ها و اطلاعات فرضی صرفاً برای نمایش قابلیت‌های طراحی استفاده شده‌اند.
